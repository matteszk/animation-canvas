AnimationCanvas

A tiny, dependency-free helper for canvas animations: sizing, the frame loop, pausing off-screen, reduced motion, image preloading and pointer tracking. View on GitHub

Warp field

Stars stream out from the center. Move your pointer up or down to change speed. Uses pointer and delta, so it runs at the same speed on any refresh rate.

Dot grid

A grid rebuilt on every resize. Dots near the pointer light up and slowly fade, with a few twinkling on their own.

Hub and spokes

Rings ripple out from a central hub every few seconds while connected services slowly orbit. Click to send a pulse and spin it up. The icons are drawn with canvas paths, so there are no images to load.

Orbits

Planets drawn from elapsed time. With reduced motion turned on, this draws one still frame instead.
